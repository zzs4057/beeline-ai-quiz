# Compliance and Responsible Use

This project is an automation and userscript engineering sample. It is not a
service for completing assessments on another person's behalf.

## Permitted intent

- Personal study assistance where automation is allowed.
- Learning how DOM observation, browser events, and API clients work.
- Testing answer extraction and editor interoperability in a controlled
  environment.

## Prohibited intent

- Bypassing exam, identity, proctoring, or anti-cheat controls.
- Submitting graded work without user review.
- Fabricating attendance, progress, grades, or completion records.
- Accessing another person's account or course data.
- Sending confidential or restricted content to a third-party API without
  authorization.

## Platform rules take precedence

If a course, employer, school, or platform prohibits AI assistance or browser
automation, do not use this project there. The maintainers do not guarantee
that page automation will not be detected or that it is permitted by any
particular platform.

## No automatic submission

The userscript stops before final submission. The user must independently
review every answer and decide whether to submit.

## No risk-control evasion

The project does not:

- Spoof page visibility or focus.
- Suppress platform events.
- Call private completion or grading APIs.
- Modify server-returned course or exam data.
- Hide automation from proctoring tools.
