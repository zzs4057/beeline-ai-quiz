# v1.2.2

首个脱敏发布版本。

## 功能

- 支持单选、多选、判断正误、单空与多空填空、中英文主观题。
- 仅保留 DeepSeek API，默认模型为 `deepseek-chat`。
- 支持富文本编辑器、字数状态校验和本地答案缓存。
- 支持“清本题缓存并重新思考”和“清空全部缓存”。
- 提供接口测试、页面结构诊断、速率限制、重试和演练模式。

## 安全与隐私

- API Key 默认值为空，只保存在油猴本地存储。
- 诊断信息不显示 API Key 前缀。
- 网络权限收紧到 `api.deepseek.com`。
- 发布物不包含截图、审计原文、第三方参考脚本、本机路径或个人账号信息。
- 增加发布物脱敏测试、隐私说明、合规说明和安全政策。

## 主观题回填

- 针对 WangEditor 5 / Slate 使用带真实 DOM 选区的 `beforeinput`。
- 不再直接修改富文本编辑器的 `textContent` 或 `innerHTML`。
- 回填后校验编辑区文字和右下角字数状态。
- 无法确认内部状态时失败关闭，保留手动编辑能力。

## 测试

- 发布物扫描：9 项。
- 核心与专项回归：124 项。
- 合计：133 项通过。

## 使用前须知

- 需要自备 DeepSeek API Key 和可用额度。
- 详细配置见仓库 `README.md` 与 `docs/configuration.md`。
- 本项目不会自动提交作业，提交前必须人工复核。
